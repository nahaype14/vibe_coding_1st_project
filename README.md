# 💰 Учёт доходов и расходов

Простое веб-приложение для учёта личных финансов: добавляйте доходы и расходы,
следите за балансом и смотрите, на что уходят деньги.

## Зачем вести учёт доходов и расходов

- **Видно, куда уходят деньги.** Категории расходов (еда, транспорт, жильё и т.д.)
  показывают, где можно сэкономить.
- **Контроль баланса.** В любой момент понятно, сколько денег остаётся после
  всех трат.
- **Финансовые привычки.** Регулярный учёт помогает планировать бюджет,
  копить на цели и избегать импульсивных трат.
- **История операций.** Можно выгрузить данные в CSV и проанализировать их
  в Excel/Google Sheets.

## Возможности

- Добавление доходов и расходов с суммой, категорией, датой и комментарием
- Сводка по доходам, расходам и балансу
- Графики: расходы по категориям (круговая диаграмма) и динамика по месяцам
- Фильтры по типу, категории, периоду и поиску по комментарию
- Выбор валюты (₽, $, €, ₸, ₴, Br, £)
- Экспорт операций в CSV
- Тёмная тема и адаптивная вёрстка под мобильные устройства
- Все данные хранятся локально в браузере (localStorage) — ничего не
  отправляется на сервер

## Технологии

React + TypeScript + Vite, Tailwind CSS, Recharts.

## Запуск проекта

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:5173`.
